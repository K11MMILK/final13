# Планировщик задач

## Описание  
Простое TODO-приложение на Go с базой SQLite и поддержкой повторяющихся задач.

## Задания со звездочкой
Реализована возможность определять извне порт при запуске сервера. Если существует переменная окружения TODO_PORT, сервер при старте будет слушать порт со значением этой переменной.
Реализована возможность определять путь к файзу БД через переменную окружения TODO_FILE.
Вычисление дат по дням, неделям, месяцам, годам.
Функция поиска.
Аутентификация с использованием JWT.
Запуск проекта в Docker.

## Запуск локально

```bash
go run main.go
```
Для проверки открыть http://localhost:7540 в браузере

## Сборка Docker-образа
Выполните команду в директории, где находится Dockerfile:
```bash
docker build -t todo-app .
```
## Запуск контейнера
```bash
docker run -p 7540:7540 --env-file .env --name todo-container todo-app
```
-p 7540:7540 — проброс порта (по умолчанию используется порт 7540)
--env-file .env — загрузка переменных окружения из файла
--name todo-container — имя контейнера

После запуска сервер будет доступен по адресу:
```bash
http://localhost:7540
```
